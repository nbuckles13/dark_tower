# Meeting Controller Navigation

## Architecture & Design
- MC architecture, actor model, session binding, capacity → ADR-0023
- User auth, meeting access, join flow → ADR-0020
- Observability: metrics facade → ADR-0011; testability (`MetricAssertion`, presence guard, rollout SLO) → ADR-0032; service-owned dashboards and alerts → ADR-0031

## Code Locations
- Service entry point → `crates/mc-service/src/main.rs`
- Config (SecretString, env loading, ac_jwks_url, TLS paths, advertise addresses, quic_max_idle_timeout_seconds) → `crates/mc-service/src/config.rs`
- Error types (McError hierarchy, From<JwtError>, MhAssignmentMissing) → `crates/mc-service/src/errors.rs`
- Auth: McJwtValidator, validate_meeting_token, validate_guest_token → `crates/mc-service/src/auth/mod.rs`
- Actors: controller, meeting, participant, messages, session (HMAC/HKDF), metrics → `crates/mc-service/src/actors/`
- Media routing control plane (ADR-0036 §7/§8/§9): per-meeting join-order slots + shared-handler edges (an edge iff the pair shares a CONNECTED handler; one handler per edge; stability; exhaustive model check under an adversarial chooser; fixed-seed property test) + pure render into `MeetingAssignment` → `crates/mc-service/src/media_routing/slots.rs`; which shared handler carries an edge (co-locate policy, correct for ANY choice) → `media_routing/edges.rs`; observed connectivity per participant (keyed by MH `connection_id`, tombstone, settle window + episode floor, bounds) → `media_routing/connectivity.rs`; frozen handler set, exact-match `resolve`, `ConnectedHandlers` (the one home for every client-facing handler url) → `media_routing/placement.rs`; output types + `egress_stream_id` packing → `media_routing/assignment.rs`; `policy_generation` (advance-only-on-change, `adopt_floor`) → `media_routing/generation.rs`; per-(meeting, handler) latest-wins push worker → `media_routing/pusher.rs`; the push + fail-loud confirm → `crates/mc-service/src/grpc/mh_client.rs`; generation eviction on both teardown paths → `crates/mc-service/src/actors/controller.rs`
- Client-facing media signalling (ADR-0036 §5/§6): capability parse (whole-declaration rejection; `SlotId`; `audio_slot_ids()` = slot demand), send directive (**no mute access — module-level invariant**; targets = handlers owning the sender's edges), slot assignments (the one `StreamAssignments` construction site; per-edge `media_handler_url`; `unreachable_sender_ids`), bounded outcome vocabularies incl. `SlotViewEmission` → `crates/mc-service/src/media_signaling/`; the meeting actor is the single composer AND the one connectivity home: slot table, frozen handler set, per-participant connectivity, push workers, last-emitted views, per-turn deferring flush bound (`SLOT_VIEW_FLUSH_BATCH`), edge-move diff + connectivity INFO lines → `crates/mc-service/src/actors/meeting_media.rs`; structural-change drivers (join, leave choke-point, capability, mute, MH connect/disconnect, settle timer arm) → `actors/meeting.rs`; connection-side validation/budget/limiters only → `webtransport/connection.rs`; test-only `MeetingSeams` (flush bound, sender-id cursor; NO placement seam) → `actors/meeting_media.rs`
- Media admission (ADR-0036 §4): meeting KEK + `u16` generation, roster `identity_public_key`, `sender_id` allocator (never reissued within one KEK generation; epoch-reset exclusion snapshot, permanent — a liveness query is the prohibited implementation) → `crates/mc-service/src/media_admission/`; KEK + namespace held as ONE value (`AdmissionEpoch`, atomic reset — "reissue before rotation" unrepresentable) → `media_admission/epoch.rs`; `MeetingKeyState::rotate` (fail closed, never wraps) → `media_admission/kek.rs`; KEK generated in `MeetingActor::spawn`, `sender_id` allocated in `handle_join` (`actors/meeting.rs`); key length-checked at the WebTransport boundary + `JoinResponse` fill (`webtransport/connection.rs`); MH→MC sender-id→user resolution: `SenderBindingOutcome` → `media_admission/binding_response.rs`, `GetSenderIdForUser`/`SenderLookup{Found,NotFound,Ambiguous}` → `actors/messages.rs` + `actors/meeting.rs:get_sender_id_for_user()`, `resolve_sender_binding()` → `grpc/media_coordination.rs`
- KEK rotation lifecycle (ADR-0036 §4 Rotation; story 2 task 9): debounce measured from the OLDEST un-rotated removal and never reset (NOT `connectivity.rs`'s last-settle window), `RotationTrigger`/`KekPushOutcome` vocabularies + alert partition, `KekLifecycle` (W, overdue threshold, fleet MAX gauges, evicted on both teardown paths), bounded outcome collector + `mc.kek.lifecycle` INFO log → `crates/mc-service/src/media_admission/rotation.rs`; leave hook on `remove_and_broadcast_left`, `rotate_due`/`rotation_failed`/`push_kek_update`, epoch reset in `handle_join`, reconnect re-issue in `handle_reconnect`, test-only `force_kek_rotation` → `actors/meeting.rs`; KEK push (`KekUpdate`, the one place a pushed KEK leaves its `Arc`) → `actors/participant.rs::handle_kek_update`; W projection → `config.rs::Config::kek_lifecycle`; fleet-gauge sampler → `main.rs`
- Join display-name plumbing: boundary truncate (connection.rs) → `display_name` field on `JoinConnection`/`ConnectionJoin` (messages.rs) → empty-claim fallback sink → `crates/mc-service/src/actors/meeting.rs:handle_join()`
- Server mute (R-8..R-11): host authority at dispatch (before any target read) + per-connection limiters + one generic refusal → `webtransport/connection.rs::handle_server_mute_request`/`refuse_server_mute`/`handle_unmute_request`; actor authority, compose rule (self and server mute independent), who-muted-whom broadcast incl. target, late-joiner replay, UnmuteRequest relay (never clears) → `actors/meeting.rs::handle_server_mute`/`handle_request_unmute`/`server_mute_replay`; per-handler muted set by edge ownership → `media_routing/slots.rs::render`, field → `media_routing/assignment.rs::HandlerAssignment`; pod muted-sources census → `actors/meeting_media.rs::MutedSourceCensus`; outcome vocabularies → `media_signaling/outcome.rs`; Meeting end + MH teardown (R-20): end-on-empty in `actors/meeting.rs::remove_and_broadcast_left`, exit-path hand-off `hand_off_teardown` (Drop-guard completion); quiesce → `EndMeeting` plan → releases, bounds (`PUSH_QUIESCE_BOUND`, `TEARDOWN_MAX`), outcome classifier → `media_routing/teardown.rs`; teardown fence (park-not-await creates, backstop deadline), GC notify after completion → `actors/controller.rs`; at-most-once GC notify + queue → `grpc/gc_client.rs::notify_meeting_ended`/`MeetingEndedQueue`; story-4 fence residual → `docs/TODO.md` "`EndMeeting` has no fence against a late `RegisterMeeting`"
- Disconnect cause / leave latency: `DisconnectCause` enum → `crates/mc-service/src/actors/messages.rs`; skip-grace on clean close + `remove_and_broadcast_left()` choke-point → `crates/mc-service/src/actors/meeting.rs:handle_disconnect()`; cause-cell (AtomicU8) → `crates/mc-service/src/actors/participant.rs`
- WebTransport: server (accept loop, TLS, capacity; config-driven max_idle_timeout/keep_alive for crash detection in `bind()`) → `crates/mc-service/src/webtransport/server.rs`
- WebTransport: connection (join flow: meeting handle + Redis handler set read BEFORE the actor join, `JoinMedia` into the join, `media_servers` = the FULL frozen handler set; bridge loop, Connection::closed() watch + classify_connection_error, MediaConnectionUpdate handler — client-reported status is diagnostic only, never connectivity) → `crates/mc-service/src/webtransport/connection.rs`
- WebTransport: handler (encode_participant_update) → `crates/mc-service/src/webtransport/handler.rs`
- gRPC: GC client (registration, heartbeats, advertise, meeting-ended notify) → `crates/mc-service/src/grpc/gc_client.rs`

## Integration Seams
- Client -> MC WebTransport (join, signaling) → `crates/mc-service/src/webtransport/server.rs`; MC <-> GC registration/heartbeat/meeting-ended notify → `crates/mc-service/src/grpc/gc_client.rs`
- GC -> MC assignment → `crates/mc-service/src/grpc/mc_service.rs`
- MH -> MC notifications (connect/disconnect; `connection_id`; binding + connectivity in ONE actor turn; `mc_mh_notifications_unapplied_total{reason}`) → `crates/mc-service/src/grpc/media_coordination.rs:resolve_and_record()` → `actors/meeting.rs:handle_media_connected()`/`handle_media_disconnected()`
- MC -> AC: token management → `crates/common/src/token_manager.rs`; JWKS (meeting token validation) → `crates/common/src/jwt.rs:JwksClient`
- MC -> MH RegisterMeeting RPC (full snapshot incl. `server_muted_sources` + `policy_generation` on every structural change; confirms the applied echo) → `crates/mc-service/src/grpc/mh_client.rs:register_meeting()`, driven by `media_routing/pusher.rs`; MC -> MH EndMeeting (after quiesce, own `mc_id`) → `grpc/mh_client.rs::end_meeting`, driven by `media_routing/teardown.rs`
- MC -> Redis session/fencing + MH assignment read → `crates/mc-service/src/redis/client.rs:get_mh_assignment()`
