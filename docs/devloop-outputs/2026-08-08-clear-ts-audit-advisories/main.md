## Task Overview

### Objective
The forced weekly Layer-6 TS audit (`DEVLOOP_AUDIT_FORCE_RUN=1 scripts/lang/ts/audit.sh`)
went red at story close. Clear all high/critical pnpm advisories so it emits STATUS=OK,
preferring a real fix (dep bump / override) over suppression.

### Current audit state (Lead recon, 2026-08-08)
`pnpm audit --audit-level=high --json` reports **exactly one** advisory at/above threshold:

- **GHSA-2v37-7h3g-55p8** (CVE-2026-67213) — `nanoid` **<3.3.17** infinite loop / DoS in
  `customAlphabet`/`customRandom` when `size=0`. Severity **high** (CVSS 5.9).
  Installed: `nanoid@3.3.16`. Patched: `>=3.3.17`.
- Path: `. > eslint-plugin-svelte > postcss > nanoid` (transitive, dev-lint-tooling only;
  also reached via `vite`/`vitest` dev deps). Not a runtime/browser-bundle dep.

### Planned fix (real fix, not suppression)
Add a `pnpm.overrides` entry for `nanoid` to root `package.json`, then `pnpm install`.
This mirrors the three existing transitive-security overrides already in the block
(`brace-expansion`, `fast-uri`, `postcss`) — minimal, tree-wide, smallest lockfile delta.
No suppression needed → `audit-suppressions.toml` untouched.

**Implementation note (divergence from literal plan, 2026-08-08):** the override was
written as `"nanoid": ">=3.3.17 <4"` (upper-bounded), NOT the literal unbounded
`">=3.3.17"`. An unbounded `>=3.3.17` override resolves to the latest `nanoid@6.0.1`,
an ESM-only major that breaks the CJS toolchain consumers (@test flagged this exact
risk at Gate 1). Bounding to `<4` mirrors the existing `fast-uri` override style
(`>=3.1.4 <4`) and resolves tree-wide to `nanoid@3.3.18`, a single patched 3.x version.
Verified: `STATUS=OK` (no `SUPPRESSED=`), `pnpm lint` + `pnpm test:unit` green.
